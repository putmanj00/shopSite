## Milestone Summary

**Key Accomplishments:**
- All fake social proof removed: purchase notification popups, fabricated testimonials ("Sarah M."), invented stats ("2,500+ Happy Seekers"), fake Instagram engagement counts
- Navigation routing fixed: /collections → /collections/all 301 redirect, all 8 stale hrefs corrected, dead /collections route deleted
- Navigation labels corrected: 6 categories (Tie-Dye, Leather, Jewelry, Crystals, Artwork, Ceramics) with correct hrefs in header dropdown and mobile drawer
- Product data quality: vendor normalization (My Store → Wildenflower), test products hidden, imageless products filtered, botanical corner overlays added
- Collections page polished: "All Treasures" heading, subtitle, BotanicalHeader, "Home > Shop > All Treasures" breadcrumb
- Footer cleaned: 7-entry SHOP column with correct hrefs; dead links (Size Guide, Sustainability, Press) removed

**Key Decisions:**
- Products with no featured image filtered client-side via isShowableProduct() — minimal overhead vs Shopify query filter
- normalizeVendor() utility placed in lib/product-filters.ts — shared across product-card, product-info, quick-view-modal
- FindUsInTheWild events section replaces Instagram gallery stub — real content from data/events.json

**Tech Debt:**
- components/cro/recent-purchase-popup.tsx: preserved on disk (not imported anywhere)
- components/social-proof-toast.tsx: preserved on disk (not imported anywhere)
- components/emails/abandoned-cart-email.tsx line 164: "Sarah M., Verified Buyer" in email template — outside storefront scope, future cleanup
