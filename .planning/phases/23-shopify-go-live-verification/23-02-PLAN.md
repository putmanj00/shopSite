Complete three external dashboard actions before the test purchase can succeed:

---

**Action A — Verify wildenflower.com in Resend:**

1. Log in to Resend at https://resend.com/domains
2. If wildenflower.com is already listed and shows "Verified" — skip to Action B
3. If not verified:
   a. Click "Add Domain" → enter `wildenflower.com`
   b. Resend shows DNS records to add (2–3 records: DKIM TXT, SPF TXT, optional DMARC)
   c. Go to your DNS provider (Cloudflare, Namecheap, etc.) and add ALL the records exactly as shown
   d. Return to Resend → click "Verify DNS Records"
   e. DNS propagation can take up to 48 hours. If not immediate, check again later before running Plan 03.

**Expected state:** Resend Domains page shows wildenflower.com with a green "Verified" badge.

---

**Action B — Register Shopify webhook + copy secret:**

(The webhook endpoint is deployed from Plan 01. Now register it in Shopify Admin so Shopify knows where to send events.)

1. Shopify Admin → Settings → Notifications → scroll to "Webhooks" at the bottom
2. Click "Create webhook"
   - Event: **Order payment** (= `orders/paid`)
   - Format: JSON
   - URL: `https://wildenflower.com/api/webhooks/order-created`
   - API version: `2025-04`
3. Save the webhook
4. On the Webhooks page, find the text: "Your webhooks will be signed with [secret]"
5. Copy the entire signing secret string

---

**Action C — Set SHOPIFY_WEBHOOK_SECRET in Vercel production:**

1. Vercel Dashboard → shopsite-prod project → Settings → Environment Variables
2. Add new variable:
   - Name: `SHOPIFY_WEBHOOK_SECRET`
   - Value: [paste the secret copied in Action B]
   - Environment: Production only (not Preview, not Development)
3. Save
4. Trigger a redeployment: Vercel → shopsite-prod → Deployments → open latest → Redeploy (or push any commit to trigger CI/deploy)
5. Confirm the new deployment goes live at `https://wildenflower.com`

---

**Verification before continuing:**
