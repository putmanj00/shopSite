**app/globals.css — botanical token reset:**

The file has a large `:root` block with psychedelic color variables, a `@theme inline` block, and two `@media (prefers-color-scheme: dark)` blocks. Make the following targeted changes:

1. **Add `color-scheme: light` to `:root`** (first property, before the color variables):
```css
:root {
  color-scheme: light;
  /* ... existing variables stay ... */
```

2. **Update semantic variables in `:root`** — change these two lines:
```css
  --background: var(--color-neutral-50);
  --foreground: var(--color-neutral-900);
```
To:
```css
  --background: #F5EDD6;   /* parchment */
  --foreground: #5C4033;   /* inkBrown */
```

3. **Delete both dark mode media query blocks** entirely:
   - The block at lines ~169–177: `@media (prefers-color-scheme: dark) { :root { --background: ...; --foreground: ...; ... } }`
   - The block at lines ~301–306: `@media (prefers-color-scheme: dark) { input, textarea, select { color: ...; background-color: ...; } }`

4. **Update the `@theme inline` block** — replace the old font mappings and add botanical tokens:
   - Remove: `--font-sans: var(--font-nunito);`, `--font-heading: var(--font-righteous);`, `--font-accent: var(--font-sacramento);`
   - Add at the top of the `@theme inline` block (before the color token mappings):
```css
  /* Wildenflower botanical palette */
  --color-parchment: #F5EDD6;
  --color-terracotta: #C8642A;
  --color-gold: #C9A642;
  --color-sage: #7B8B6F;

  --color-dusty-rose: #D08B7A;
  --color-ink-brown: #5C4033;
  --color-earth: #3B2F2F;

  /* Wildenflower font utilities */
  --font-playfair: var(--font-playfair);
  --font-lora: var(--font-lora);
```

5. **Update base `body` styles** in the BASE STYLES section:
```css
body {
  background: var(--background);
  color: var(--foreground);
  font-family: var(--font-lora), Georgia, serif;
  font-size: var(--font-size-base);

```

6. **Update heading styles** in the BASE STYLES section. Change:
```css
h1, h2, h3, h4, h5, h6,
.font-heading {
  font-family: var(--font-righteous), system-ui, sans-serif;
```

To:
```css

  font-family: var(--font-playfair), Georgia, serif;
  font-weight: 700;
}
```
Remove the `.font-accent` block entirely.

**CRITICAL — do NOT remove the old `:root` psychedelic color variables** (the `--color-primary-*`, `--color-secondary-*`, etc. blocks). Per research, those may be referenced by existing components via `var()`. They stop generating Tailwind utilities once removed from `@theme inline`, which is sufficient. Leave the `:root` color variable declarations intact.
