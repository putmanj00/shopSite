**Change 2 — Add botanical corner overlays.**
Inside the same `<div className="relative aspect-square overflow-hidden ...">`, AFTER the Quick View button and BEFORE the closing `</div>`, add the two corner overlay images:

```tsx
{/* Botanical corner overlays — decorative, pointer-events-none so they don't intercept clicks */}
<Image
  src="/assets/images/corners/card-corner-topleft.png"
  alt=""
  aria-hidden="true"
  width={60}
  height={60}
  className="absolute top-0 left-0 z-10 pointer-events-none select-none"
/>
<Image
  src="/assets/images/corners/card-corner-bottomright.png"
  alt=""
  aria-hidden="true"
  width={60}
  height={60}
  className="absolute bottom-0 right-0 z-10 pointer-events-none select-none"
/>
```

Z-index notes — do not change these:
- Corner overlays: z-10 (above product image, below wishlist)
- WishlistButton wrapper: z-20 (unchanged — stays clickable)
- Quick View button: no z-index (unchanged — corners are pointer-events-none so hover still works)

The `width={60} height={60}` props control the intrinsic size passed to Next.js Image for optimization. The actual displayed size is governed by the className. If the PNGs are larger than 60px naturally, Next.js will still render them at 60px display size via the Tailwind classes — this is the correct approach per the research.
