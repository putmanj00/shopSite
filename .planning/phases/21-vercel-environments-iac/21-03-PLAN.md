  <action>
Find the `deploy-prod` job in `.github/workflows/ci.yml`. It currently contains:
```yaml
      - run: echo "Production deployment — Phase 21 will implement Vercel deploy here"
```

Replace that job's steps with a real Vercel CLI deploy. The full deploy-prod job should become:

```yaml
  deploy-prod:
    needs: [quality, e2e, secrets-scan, audit]
    runs-on: ubuntu-latest
    environment: production
    if: github.ref == 'refs/heads/main' && github.event_name == 'push'
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - name: Install Vercel CLI
        run: npm install -g vercel@latest
      - name: Pull Vercel environment
        run: vercel pull --yes --environment=production --token=${{ secrets.VERCEL_TOKEN }}
        env:
          VERCEL_ORG_ID: ${{ secrets.VERCEL_ORG_ID }}
          VERCEL_PROJECT_ID: ${{ secrets.VERCEL_PROJECT_ID_PROD }}
      - name: Build project
        run: vercel build --prod --token=${{ secrets.VERCEL_TOKEN }}
        env:
          VERCEL_ORG_ID: ${{ secrets.VERCEL_ORG_ID }}
          VERCEL_PROJECT_ID: ${{ secrets.VERCEL_PROJECT_ID_PROD }}
      - name: Deploy to production
        run: vercel deploy --prebuilt --prod --token=${{ secrets.VERCEL_TOKEN }}
        env:
          VERCEL_ORG_ID: ${{ secrets.VERCEL_ORG_ID }}
          VERCEL_PROJECT_ID: ${{ secrets.VERCEL_PROJECT_ID_PROD }}
```

Key attributes to preserve:
- `environment: production` — this is the GitHub environment gate that requires manual approval (Phase 20 requirement, must not be removed)
- `if: github.ref == 'refs/heads/main' && github.event_name == 'push'` — only deploys on main push, not PRs
- `needs: [quality, e2e, secrets-scan, audit]` — all checks must pass first

After editing, commit the change to a new branch and open a PR to verify the pipeline.
