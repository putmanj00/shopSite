Create `.github/workflows/ci.yml` with the following exact structure. Create the `.github/workflows/` directory if it does not exist (only `dependabot.yml` is currently in `.github/`).

The workflow must have these five jobs with these exact `name:` values (names appear as GitHub PR check names — branch protection in Plan 03 will reference them exactly):

**Job: `quality`**
- name: `Quality (lint / typecheck / build)`
- runs-on: ubuntu-latest
- Steps: checkout@v4, setup-node@v4 (node 22, cache npm), npm ci, `npm run lint`, `npm run typecheck`, `npm run build`
- Build step env vars: SHOPIFY_STORE_DOMAIN, SHOPIFY_STOREFRONT_ACCESS_TOKEN, SHOPIFY_SHOP_ID (all from ${{ secrets.* }}), NEXT_PUBLIC_BASE_URL: https://wildenflower.com
- No env vars needed on lint or typecheck steps

**Job: `e2e`**
- name: `E2E (${{ matrix.browser }})`
- needs: quality
- runs-on: ubuntu-latest
- strategy: fail-fast: false, matrix.browser: [chromium, firefox, webkit]
- Steps: checkout@v4, setup-node@v4 (node 22, cache npm), npm ci, `npx playwright install --with-deps`, `npx playwright test --project=${{ matrix.browser }}`
- Test step env: CI: true, SHOPIFY_STORE_DOMAIN, SHOPIFY_STOREFRONT_ACCESS_TOKEN, NEXT_PUBLIC_BASE_URL: http://localhost:3000
- Upload step: actions/upload-artifact@v4, if: ${{ !cancelled() }}, name: playwright-report-${{ matrix.browser }}, path: playwright-report/, retention-days: 30
- Do NOT cache Playwright browsers — Playwright docs explicitly advise against it (restore time ≈ download time)

**Job: `secrets`**
- name: `Secrets Scan`
- runs-on: ubuntu-latest
- Steps: checkout@v4 WITH fetch-depth: 0 (required for full history scan — shallow clone produces false negatives), gitleaks/gitleaks-action@v2
- gitleaks step env: GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
- No GITLEAKS_LICENSE needed (personal repo)

**Job: `audit`**
- name: `npm audit`
- runs-on: ubuntu-latest
- Steps: checkout@v4, setup-node@v4 (node 22, cache npm), npm ci, `npm audit --audit-level=high --omit=dev`
- Use --omit=dev because minimatch high-severity vulns are in @typescript-eslint (devDep)

**Job: `deploy-prod`**
- name: `Deploy to Production`
- needs: [quality, e2e, secrets, audit]
- runs-on: ubuntu-latest
- environment: production
- if: github.ref == 'refs/heads/main' && github.event_name == 'push'
- Steps: single step — `echo "Production deployment — Phase 21 will implement Vercel deploy here"`
- This job is a placeholder stub; the `environment: production` field is what creates the manual approval gate (configured in GitHub Settings in Plan 03)

**Workflow triggers:**
```yaml
on:
  pull_request:
    branches: [main]
  push:
    branches: [main]
```
No `draft: false` filter — CI runs on draft PRs by default (per locked decision).
Deployment only fires on push to main (the if condition handles this), so draft PRs naturally get CI but no deploy.

Do NOT use separate workflow files. Do NOT add caching for Playwright browsers. Do NOT use @playwright/test — tests use `playwright` package.
