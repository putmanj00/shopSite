## Code review

Pull requests are reviewed by **Codex cloud code review** (OpenAI). Codex reads the
repo-root `AGENTS.md`, which encodes the brand/slop gate and the P0/P1 severities it flags
against.

- **Trigger:** comment `@codex review` on a PR (or enable Automatic reviews in the repo's
  Codex cloud settings). Adding Codex to the PR reviewers list does not trigger it.
- **Fixes:** comment `@codex fix it` to spawn a fix task for a flagged finding.
- **Scope:** a cloud surface billed against OpenAI's Code Review usage meter. It
  complements — does not replace — lefthook pre-commit and `ci.yml`, which stay authoritative.
