# Ralph Progress Log
Started: Sun Jan 12 2026

## Codebase Patterns

- **Next.js Setup**: Using Next.js 14+ with App Router (not Pages Router)
- **TypeScript**: Strict mode enabled for maximum type safety
- **Styling**: Tailwind CSS v4 with PostCSS for modern utility-first styling
- **Code Quality**: ESLint + Prettier configured for consistent code style
- **Import Aliases**: Using `@/*` for clean imports from project root
- **Quality Scripts**: `npm run typecheck`, `npm run lint`, `npm run build` must all pass before committing
- **Shopify API**: Use lazy-loaded client pattern (lib/shopify.ts) to avoid build-time errors with environment variables
- **GraphQL**: Queries stored in lib/shopify-queries.ts with reusable fragments for maintainability
- **API Helpers**: Use helper functions from lib/shopify-helpers.ts for all Shopify operations (includes error handling)
- **React Components**: No JSX in try/catch blocks (ESLint rule) - separate data fetching from rendering
- **Server Components**: Use async server components for data fetching, wrap in Suspense for loading states
- **Responsive Design**: Mobile-first with Tailwind breakpoints (sm, md, lg, xl)

**Learnings for Future Iterations**:
- **Lazy Loading for Build Success**: Module-level code that requires environment variables will break Next.js builds. Use lazy loading (create client on first use) instead of module-level initialization
- **GraphQL Fragments**: Use fragments to keep queries DRY and maintainable - defined MoneyFragment, ImageFragment, VariantFragment, ProductFragment
- **Error Handling Pattern**: Wrap all Shopify API calls in try/catch, check for response.errors, and provide helpful error messages
- **API Version**: Using Shopify API version '2024-01' - update periodically as Shopify releases new versions
- **Test Route**: The /api/test-shopify endpoint can be used to verify Shopify credentials are configured correctly
- **TypeScript Types**: Created comprehensive types matching Shopify's GraphQL schema for compile-time safety

- components/featured-products.tsx - Server component fetching and displaying featured products

**Learnings for Future Iterations**:
- **No JSX in Try/Catch**: ESLint rule `react-hooks/error-boundaries` prevents JSX construction inside try/catch blocks. Solution: Separate data fetching (in try/catch) from JSX rendering, or create separate component functions for error/empty states
- **Server Components**: Featured products is an async server component that fetches data at request time. Next.js handles this seamlessly with Suspense boundaries
- **Skeleton Loading**: Use skeleton components with `animate-pulse` class for better perceived performance
- **Metadata API**: Next.js 14+ App Router uses export const metadata for SEO - supports templates, OpenGraph, Twitter Cards, and robots
- **Image Optimization**: Using Next.js Image component with `fill` and `object-cover` for responsive product images
- **Tailwind Responsive**: Grid responsive breakpoints - grid-cols-1 (mobile), sm:grid-cols-2 (tablet), lg:grid-cols-3, xl:grid-cols-4 (desktop)
