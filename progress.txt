# Ralph Progress Log
Started: Sun Jan 12 2026

## Codebase Patterns

- **Next.js Setup**: Using Next.js 14+ with App Router (not Pages Router)
- **TypeScript**: Strict mode enabled for maximum type safety
- **Styling**: Tailwind CSS v4 with PostCSS for modern utility-first styling
- **Code Quality**: ESLint + Prettier configured for consistent code style
- **Import Aliases**: Using `@/*` for clean imports from project root
- **Quality Scripts**: `npm run typecheck`, `npm run lint`, `npm run build` must all pass before committing
- **Shopify API**: Use lazy-loaded client pattern (lib/shopify.ts) to avoid build-time errors with environment variables
- **GraphQL**: Queries stored in lib/shopify-queries.ts with reusable fragments for maintainability
- **API Helpers**: Use helper functions from lib/shopify-helpers.ts for all Shopify operations (includes error handling)
- **React Components**: No JSX in try/catch blocks (ESLint rule) - separate data fetching from rendering
- **Server Components**: Use async server components for data fetching, wrap in Suspense for loading states
- **Responsive Design**: Mobile-first with Tailwind breakpoints (sm, md, lg, xl)
- **URL State Management**: Use Next.js useRouter and useSearchParams for persisting filter/sort state in URL
- **Client Components**: Use 'use client' directive for components with interactivity (useState, useEffect, event handlers)
- **Debouncing**: Use useRef with setTimeout for debounced inputs (e.g., search bars)
- **React ESLint Rules**: Avoid setState in useEffect - use component keys to reset state or initialize from props
- **State Management**: Use Zustand for global state (cart, user session) - simpler than Context API, automatic re-renders, persist middleware for localStorage
- **Cart Integration**: Shopify cart mutations handle all cart operations - create cart on first add, use cartId for subsequent operations
- **Error Handling**: Check both response.errors and userErrors from GraphQL mutations - use Array.isArray before mapping errors

- **Filter Logic**: Apply filters client-side using useMemo for performance - filter, then sort, then paginate
- **Type Safety**: Pass all searchParams through Promise unwrapping in Next.js 15+ (async params and searchParams)
